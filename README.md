# CollegeFinder

CollegeFinder is a College Discovery Platform built as an internship demo project.

## Features

- Search colleges by name or city
- College listing with rating and fees
- College detail pages
- Courses, fees and placement information
- Compare 2–3 colleges
- Responsive user interface

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Git & GitHub
- Vercel
